# FTIR plotting

Publication-style FTIR helpers from the current `cursorplots` suite.

Set `FTIR_DATA_DIR` to a folder of two-column CSV spectra (not included).
Optional: `FTIR_BACKGROUND_CSV`, `CALCULATED_PEAKS_CSV`.

```bash
export FTIR_DATA_DIR=/path/to/your/spectra
python3 perovftir_plots.py
```
