# Min-pressure analysis figures

Publication plots from the group-resolved normal-mode study at 0 / 4 / 10 GPa (minpress cohort).

Mode trajectory data (`anime_*.xyz`) is **not** in this repository. These PNGs are included so results are visible without rerunning the pipeline.

Regenerate locally with your own trajectories via `run_group_analysis.py` (see parent README).
